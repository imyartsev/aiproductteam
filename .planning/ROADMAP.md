### Phase 3: Демо-прогон
**Goal**: Полный pipeline выполняется с задачей "Создай FastAPI сервис для управления задачами" и генерирует запускаемый код
**Mode:** mvp
**Depends on**: Phase 2
**Requirements**: DEMO-01, DEMO-02, DEMO-03, DEMO-04
**Success Criteria** (что должно быть ИСТИННО):
  1. Команда `python main.py "Создай FastAPI сервис для управления задачами"` завершается без ошибок — все 6 агентов отработали
  2. **PO-агент**: `01_task_spec.md` содержит user stories формата "Как пользователь, я хочу..." и критерии приёмки для CRUD-операций с задачами
  3. **Architect-агент**: `02_arch_decision.md` содержит выбор стека (FastAPI, SQLite/PostgreSQL, ORM) с обоснованием и структуру проекта
  4. **Analyst-агент**: `03_tech_spec.md` содержит API-контракты (эндпоинты, методы, схемы запросов/ответов) и модели данных
  5. **Dev-агент**: реальные `.py`-файлы в `projects/<slug>/` — как минимум `main.py` и модели данных
  6. **QA-агент**: реальные тестовые `.py`-файлы в папке проекта — как минимум один тест на каждый CRUD-эндпоинт
  7. **DevOps-агент**: `Dockerfile` и CI-конфиг в папке проекта
  8. Команда `uvicorn` запускает сгенерированный FastAPI сервис без ручных правок
  9. Команда `pytest` проходит все сгенерированные тесты
