**Status:** ✅ SHIPPED 2026-05-08

**Total Plans:** 5

## Overview

Первый рабочий milestone проекта AI Product Team. Цель — закрыть три ключевых пробела: исправить баг с флагом reasoner, научить pipeline создавать настоящие файлы из markdown-вывода агентов, и провести полный демо-прогон. После завершения пайплайн выдаёт запускаемый FastAPI сервис от текстовой задачи до Dockerfile.

## Milestone Summary

**Key Decisions:**
- `use_heavy_model` → `use_reasoner`: атрибут переименован для корректной активации reasoner-модели (D-01/D-02)
- Парсер `# path:` маркеров — агент пишет свободно в markdown, потом парсим (без изменения архитектуры агентов)
- `python:3.10-slim` зафиксирован как единственный допустимый базовый образ Docker
- Структура `app/` для сгенерированного кода — единообразие между Dev, QA, DevOps промптами
- `python -m pytest` вместо прямого `pytest` для гарантии доступности в PATH
- `shutil.rmtree` в `pipeline.py` перед записью — предотвращение накопления файлов между прогонами

**Issues Resolved:**
- Флаг HEAVY_MODEL не активировал reasoner-модель (несовпадение имён атрибутов `use_heavy_model` vs `use_reasoner`)
- Dev-агент не создавал реальные файлы (только markdown-отчёт в `04_code.md`)
- Конфликт путей между Dev (`app/`) и DevOps (`src/`) промптами
- `tests/` исключался в .dockerignore, нарушая pytest в Docker
- `pytest` отсутствовал в PATH при запуске через `docker run pytest`
- `python:3.12-slim` недоступен в локальном кэше Docker

**Issues Deferred:**
- Path traversal (T-2-01) — LLM-вывод используется для создания файлов без валидации путей (REL-04 в backlog)
- Retry-логика при ошибках DeepSeek API (REL-01, REL-02, REL-03)

**Technical Debt Incurred:**
- REQUIREMENTS.md не обновлялся в ходе milestone (статус Pending не менялся по мере выполнения этапов)
- ROADMAP.md прогресс-таблица не обновлялась автоматически после выполнения этапов 2 и 3
